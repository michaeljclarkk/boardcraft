# 24-android-board-navigation

Start Android Kit with action `dev.boardcraft.BROWSE` and a loopback port, without a board UUID. Use the existing origin-scoped restore/sign-in flow. Display `EditClient::list_boards` in returned order; a tap reads just that UUID with `read_selected_board`. Display the accepted item titles read-only. Back from a selection or unavailable destination reloads visibility; refreshing the picker never replays a tap. Keep no-arguments offline mode and the board/port edit entry.

The mobile reference opens its workspace sidebar from Home through a hosted menu command. Selecting an active board follows its UUID and closes the sidebar. System Back handles transient UI first, then history or Home. This packet implements the bounded picker as the only prior screen; its Back reload is not evidence that the reference always reopens the sidebar.
