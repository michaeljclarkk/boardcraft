# 08-cross-client-reopen

Run the complete 07 rejection/correction journey on one fresh fixture, then distinguish an accepted name from a subsequent unsaved draft across two native clients. Gate: `node scripts/cross-client-reopen.mjs`, on the dedicated AVD with a graphical Windows session and `rustday_test`.

- After saving `Coral` in the second Android row, open that row again, replace it with `Amber` in the real Kit Input and dismiss the IME without saving. HOME must stop/background the activity. Bring its task back: require the same process and local activity instance, the sibling above the `Amber` editor, and a fresh store check of the **accepted** `Coral` (revision 2). An app crash/relaunch does not count as resume.
- While `Amber` is still an Android draft, open a Windows GPUI window on that exact board UUID and fixture schema. Extend the desktop `native-smoke` driver with `--smoke-delivery`: inspect the two **visible input controls** and their top-to-bottom order, clean row state and bound IDs. Emit one observed line per control: `row <board-uuid> <item-uuid> <value>` and close. The gate compares against the fixture's known IDs (42 then 17 as UUID integers) and accepted values. The host fixture must include its generated `schema` name in its startup JSON; only the desktop child gets the scoped database URL.
- Force-stop only the fixture package, confirm its process exited, then launch the activity with the same UUID and port. Require a different process, display-mode `Review sketch` / `Coral`, no editor or `Amber`, and unchanged IDs/order/revisions on a fresh read. This is cold process/activity recreation and explicit reopen. Do not claim same-process configuration-change recovery, navigation Back confirmation, live conflict/revalidation or durable draft restoration. The draft belongs to the live view; do not serialize it or submit it on stop.
- Inherit 06/07 and portable checks. Preserve the desktop smoke driver and rerun its original suite. If the worker cannot run the device/window gate, document actual local checks and wait for operator evidence; do not change permissions or mark the packet verified by hand.
