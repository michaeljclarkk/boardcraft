# 45-windows-grouped-item-entry

Make the Windows browse table usable for entering work: add a root in a physical group, then edit its name inline on that board. Use the accepted [group create](32-browser-group-item-create.md), [selected-board name editor](29-browser-selected-name.md) and [Windows edit interaction](09-windows-name-cell.md) as the comparison. Apply both GPUI skills. Reuse the existing create and rename rule owners, title validation, IDs and access checks. Use narrowly scoped native selected-board contracts; keep direct-target and flat behavior intact.

- A writable expanded group offers a draft keyed by group ID. Enter or Add submits; blank, Escape and blur do not create. Preserve the raw draft and proposed UUID on validation rejection, and preserve other groups’ drafts when replacing the accepted table. Show no pending row until commit. Folded groups expose no body controls.
- Rename the new root by UUID, including when its sibling has the same spelling. Support focus, double-click/F2, raw input, Escape, Enter and blur as in the existing name editor. An unchanged name sends nothing. Keep the accepted rows, counts, order and group identity accurate after a fresh read. Expose read-only cells to a Viewer. Explicit correction/review after a rejection; a lost acknowledgment triggers read-only reconciliation, never an automatic write replay. A demoted Member must lose write actions on refresh, and a revoked session must return to sign-in.
- `windows_creates_and_renames_grouped_root`: drive the actual Kit inputs using the packet 44 two-Work fixture. Cancel a draft, correct an overlong draft in the second Work to ` Ink `, append exactly one root, then cancel and complete a rename of only that new Ink to `Coral`. Revisit: same ID, accepted spelling and position; both namesakes, other group, folds and sibling board remain intact. Confirm values/revisions with a fresh connection.
- `windows_recovers_grouped_item_entry`: exercise a mid-edit demotion, validation recovery and an uncertain commit or failed confirmation. Inspect request counts and DB state before and after recovery. `native_grouped_item_entry_checks_current_access`: exercise native selected create/rename over HTTP, including an inaccessible board, wrong group/item, unchanged direct target boundaries and current roles.

Worker runs the focused cases, then hands off once. Runner owns the inherited selected-board/Windows suites, workspace checks, format and runner regressions. Reuse fixtures and drivers rather than building a new harness.
