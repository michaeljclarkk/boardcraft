# 15-android-kit-sign-in

On connected launch, use real Kit inputs for identifier → Next → masked password → Sign in. Advance on a nonempty identifier without an account lookup. Compare the wrong-password/retry flow to the existing-account reference. Only after a successful login and session resolution may the app load the protected board using the returned bearer. No credentials at launch; no anonymous access. Keep the session in memory for this slice. On cold reopen, sign in again. Preserve the no-network fixture without launch extras.

Run the connected UI journey on the dedicated emulator with a disposable private board and Member. Rejection must leave zero sessions and both original rows intact on a fresh connection. Retry in the UI, save the corrected title, verify row IDs, ordering and revisions, then run the 08 HOME/resume, Windows readback and cold reopen on that board. Also run the offline 06 frame and both 05 device probe cases. Never supply passwords or bearers via process arguments, logs, screen captures or packaged files. Coordinator owns the tracked drivers. Worker owns Rust/Android, the fixture helper and handoff.

Driver contract: connected login uses the visible placeholders `Username or email` and `Password` and buttons `Next` and `Sign in`. On invalid credentials show `Incorrect username or password` and allow correction. For the test only, the host driver sends a one-use random lowercase hex fixture password on the fixture process's stdin before its first JSON response. The fixture seeds an active `boardmember` account with that password and board access, without a session. `rejected` verifies zero sessions and original board; `signed-in` verifies one session and original board. Keep `original` and `saved` checkpoints. The fixture must never emit the password or a token. The driver enters the generated password into the masked control via input events. Do not take frames while typing a password. On retry support retaining or clearing the masked field; the driver replaces its contents explicitly.
